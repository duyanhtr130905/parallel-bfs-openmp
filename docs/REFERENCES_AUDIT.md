# Kiểm tra nguồn — 05/11/2026

- Springer: https://link.springer.com/book/10.1007/978-3-319-98833-7
  Đã xác minh tên sách, bốn tác giả, năm 2018 và DOI. Chương 2: Overview of
  Parallel Systems; Chương 3: Programming Multi-Core and Shared Memory
  Multiprocessors Using OpenMP. Chưa đọc toàn văn; không trích trang/câu chưa xem.
- https://github.com/minhhhduc/svd/tree/main/LATEX_template và main.tex:
  đã xem danh sách file và trình tự bìa, tóm tắt, mục lục, danh mục hình/bảng,
  sáu chương, bibliography. Chỉ tham khảo tổ chức; nội dung báo cáo mới do nhóm viết.
- https://github.com/chibinz/ParallelBFS : đã xem metadata và cây thư mục;
  chưa audit mã thuật toán. Không sao chép code hay số liệu README.
  Trước tham khảo implementation phải pin SHA, kiểm tra giấy phép, condition
  visited (source/unvisited có bị nhầm), atomic claim, parent update consistency,
  hàng rào mức, kích thước frontier và chất lượng oracle/test input.
  Đây là checklist kiểm tra, không tuyên bố đã chứng minh bug tại revision hiện tại.

references.bib chỉ chứa nguồn đã xác minh tồn tại. Repo tham khảo không phải
nguồn chứng minh tính đúng hoặc hiệu năng của implementation nhóm.
